
Library Management System
Project Overview
The Library Management System is a web application developed to help manage library operations. It allows users to manage books, monitor stock, borrow and return books, and manage library users.
Technologies Used
•	React.js
•	JavaScript
•	CSS
•	Node.js
•	Express.js
•	MySQL
•	Git and GitHub

Main Features
•	User login and authentication
•	Role-based access for Admin, Librarian, and Member
•	Dashboard showing library statistics
•	Add, edit, and delete books
•	Manage book stock
•	Borrow and return books
•	View transaction history
•	Manage library users
•	Search for books
•	Low-stock notifications

User Roles
Administrator
•	Access all system pages.
•	Manage books, users, and transactions.

Librarian
•	Manage books and stock.
•	Manage borrowing and returning transactions.

Member
•	View available books.
•	Borrow and return books.

Project Structure
•	backend/ – Express.js server and API.
•	src/ – React application source code.
•	public/ – Public frontend assets.
•	package.json – Frontend dependencies and scripts.
  
  
  Installation and Setup

1.	Clone the repository.
2.	Install frontend dependencies using npm install.
3.	Install backend dependencies by entering the backend folder and running npm install.
4.	Configure the backend .env file with your database credentials.
5.	Start the backend server using node server.js.
6.	Start the frontend using npm run dev.

Database
The application uses MySQL to store books, users, and transactions.
